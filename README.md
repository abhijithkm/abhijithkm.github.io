# abhijithkm.space

Personal portfolio of Abhijith K M — software engineer, Kerala, India.

Live at **[abhijithkm.space](https://abhijithkm.space/)**, served by GitHub Pages from the `gh-pages` branch.

## Stack

- React (Create React App)
- Plain CSS with design tokens (light/dark theme)
- All content lives in [`src/config/data.js`](src/config/data.js) — edit that file to update skills, experience, projects, or education.

## Develop

```sh
npm install
npm start        # dev server at http://localhost:3000
```

## Deploy

```sh
npm run build
```

Push the contents of `build/` to the `gh-pages` branch (keep the `CNAME` file so the custom domain stays attached).
