Privacy Policy — MyWorkDay

Last updated: September 17, 2026

MyWorkDay is a personal, local-first desktop application for a single developer to track their own workday. This policy explains what data the app touches and how it is handled.

Summary

MyWorkDay does not have a server, does not collect analytics or telemetry, does not create user accounts, and does not share any data with third parties. All data the app gathers stays on your own computer, in a local database, for your own use.

What data the app accesses

MyWorkDay only accesses data you explicitly configure it to access, using your own credentials:

  • Local Git history — commit metadata (timestamps, messages, branches) from repositories you point the app at, read directly from your local .git folders. This never leaves your machine.
  • Jira — your assigned tickets (key, summary, status, priority, type), fetched read-only using an API token you provide. MyWorkDay never edits, comments on, or transitions tickets.
  • Bitbucket — pull requests and their metadata in repositories you have access to, fetched read-only via an OAuth connection you authorize. MyWorkDay never creates, approves, merges, or comments on pull requests.
  • Google Calendar — your calendar events (title, start/end time), fetched read-only via a Google OAuth connection you authorize. MyWorkDay never creates, edits, or deletes events.
  • Google Chat (optional) — your own availability status (Active/Away/Do Not Disturb), read via a Google OAuth connection you authorize. MyWorkDay only changes your status when you explicitly click a button to do so — never automatically.

Where your data is stored

Everything MyWorkDay gathers is stored locally in a SQLite database on your own computer, under your OS user profile. There is no cloud backend, no remote server, and no external database. Nothing is uploaded anywhere except the specific, read-only API calls above, made directly from your computer to Jira, Bitbucket, and Google using your own credentials.

Credentials and tokens

OAuth tokens (Bitbucket, Google Calendar, Google Chat) are encrypted at rest using your operating system's own secure storage (Windows DPAPI via Electron's safeStorage). Your Jira API token is never stored in plaintext in the database. MyWorkDay never sees or stores your Google, Jira, or Bitbucket account password — authentication happens through each provider's own login screen.

Data sharing

MyWorkDay does not share, sell, or transmit any of your data to any third party. The only network requests the app makes are the read-only API calls listed above, directly to Jira, Bitbucket, and Google, authorized by and acting on behalf of you alone.

Analytics and telemetry

None. MyWorkDay does not use analytics, crash reporting, or any telemetry service.

Data retention and deletion

Your data remains in the local database until you delete it yourself (e.g., by uninstalling the app or removing its data folder). Disconnecting an integration (Bitbucket, Google Calendar, Google Chat) in Settings deletes that integration's stored token from your device immediately.

If this policy changes, the updated version will be published at the same location.
